Description of Features (Columns)
City -	Host city of the Olympics (e.g., Montreal, Seoul, Beijing) -	Text
Year -	Olympic year (1976 to 2008) -	Numeric
Sport -	Main sport category (e.g., Aquatics, Athletics, Gymnastics) -	Text
Discipline -	Specific discipline within the sport (e.g., Diving, Swimming) -	Text
Event -	Specific event name (e.g., 100m Freestyle Men) -	Text
Athlete -	Name of the medal-winning athlete -	Text
Gender -	Athlete's gender (Men / Women) -	Text
Country_Code -	3-letter country code (USA, KOR, RUS, etc.) -	Text
Country -	Full country name -	Text
Event_gender -	Gender category of the event (M / W) -	Text
Medal -	Type of medal won (Gold / Silver / Bronze) - Text
